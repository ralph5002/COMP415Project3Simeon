For this project a desktop application is written in Go utilizing a Fyne Toolkit. The intended function is that you pick a region and once clicked upon you receive all
the relevant information for the country. After utilizing an API key gained from the internet, programming they key, and installing and running the dependencies (i.e Fyne needing a C compiler)
An expected trial of usage is expected to proceed as follows:
- Choose a region (Africa, Americas, Asia, Europe, Oceania)
- Select a country from the chosen region
- Read, enjoy, or utilize the details that appear at your discretion
    - Official Name: How a nation addresses itself to the world
    - Common Name(s): How the country is most commonly addressed?
    - Official language(s): How residents speak in the country
    - Flag: The country's national representation
    - Landlocked: Does the country have lands bordering it?
    - Capital(s); The capital(s) of the nation
    - Population: Estimated population of the country 
- Choose a new region at any time to load a new list
If the key is missing the program will reflect that by having a disabled drop down list

I decided to use region as the distinguisher since I believed that most people educated to the sixth grade level would
know how to pick their desired country as opposed to more difficult means such as constantly shifting international alliances.
All the details I added seemed relevant in the overview of a country as well as clarifying common names to avoid confusion or improper representation.
